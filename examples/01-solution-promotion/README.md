# Solution Promotion

This example shows the first Article 01 implementation for promoting one Fabric solution through `develop`, `release`, and `main` using Azure DevOps.

## Contents

- `deploy_workspace_fabric.py` - the deployment entrypoint
- `azure-pipelines.yml` - the Azure DevOps pipeline
- `env.example` - local environment variable template
- `QUICKSTART.md` - the shortest path to a working run
- `TROUBLESHOOTING.md` - common failure modes and fixes

## Intended Use

Copy this example into an Azure DevOps-backed repository when you need a single, repeatable promotion path for one Fabric solution.
