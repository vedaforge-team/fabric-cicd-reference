# v1.0.0

## Release Summary

Version `v1.0.0` is the first public release of the Microsoft Fabric solution promotion reference implementation.

It demonstrates how one Fabric solution moves through `develop`, `release`, and `main` using Azure DevOps, a service principal, and environment-specific variable groups.

## Features

- Service principal authentication for Fabric deployment
- Variable-driven workspace deployment
- Validation-only branch behavior
- UAT deployment from `release`
- PROD deployment from `main`
- Sanitized screenshots and diagrams

## Prerequisites

- Azure DevOps project and repository
- Fabric workspaces for DEV, UAT, and PROD
- A service principal with workspace access
- Variable groups for the three environments
- Python 3.10 or later for local validation

## Tested Deployment Path

The tested path is:

`develop` -> `release` -> `main`

Validation runs on `develop`, UAT deployment runs on `release`, and PROD deployment runs on `main`.

## Known Limitations

- Warehouse schema deployment is intentionally excluded.
- The release package focuses on one solution, not multi-solution promotion.
- The Gist package contains the script, env template, and README only.
