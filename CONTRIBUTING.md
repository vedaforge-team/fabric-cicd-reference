# Contributing

This repository is a public reference implementation for enterprise platform engineering patterns.

## What to Contribute

- Reusable automation code
- Public-safe pipeline templates
- Sanitized diagrams
- Example layouts that work without customer-specific data
- Documentation that helps another engineer reproduce the pattern

## What Not to Contribute

- Secrets
- Tenant IDs
- Workspace IDs
- Subscription IDs
- Local file paths
- Private planning notes
- Customer names

## Expectations

- Keep changes generic and reusable.
- Keep examples aligned with the article flow.
- Keep files small enough that another engineer can copy the pattern into their own repository without guesswork.
